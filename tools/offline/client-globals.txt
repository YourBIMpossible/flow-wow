# Every global of the game client that Flow's Lua reads by name. One list,
# two readers:
#   * .luacheckrc (tools/lint.ps1): reading a global that is not here, not a
#     Lua 5.1 global and not one of Flow's own is a lint warning.
#   * tools/offline/stubs.lua (tools/run-tests.ps1): the same, at run time: an
#     unknown global is an ERROR (or a file that did not load), never a
#     "needs the client" SKIP.
# So a typo (UnitLevle) or a missing "ns." (Distance instead of ns.Distance)
# fails both checks instead of passing as "the game must have that".
#
# The list is what Flow's source refers to, not a list of the game's API, and
# nothing here says the client really has a name: that is checked in the game.
# Adding a line is a statement that you looked the name up. One name per line,
# sorted, exact case. tools/lint.ps1 fails on a name no Lua file uses any more.
#
# A line with * is a pattern for names Flow builds at run time and looks up
# through _G (_G["ContainerFrame" .. i]): * stands for any run of letters,
# digits and underscores, spaces too. luacheck doesn't read those lines.
